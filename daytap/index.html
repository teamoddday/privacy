데이탭 개인정보처리방침

시행일: 2026년 11월 4일

Oddday는 데이탭에서 사용자가 작성한 기록을 다음과 같이 처리합니다.

1. 기록 저장

데이탭은 계정 가입 없이 사용할 수 있습니다. 항목, 날짜별 기록, 메모, 테마와 표시 설정은 사용자의 기기에 저장됩니다. 개발자의 서버로 전송하거나 다른 기기와 자동 동기화하지 않습니다.

2. 수집 및 제공

이 버전의 Android 앱에는 광고, 분석, 로그인, 원격 오류 수집 SDK가 없으며, 개발자가 사용자의 기록이나 기기 식별자를 수집·판매·제3자에게 제공하지 않습니다.

업데이트 확인(Android 1.0.1 이상)

앱을 열 때 Google Play 업데이트 라이브러리로 이 기기에서 설치할 수 있는 새 버전이 있는지 확인합니다. 이 과정에서 Google Play는 기기 메타데이터, 앱 버전, 설치된 모듈 및 애셋 팩 정보를 업데이트 제공 여부와 크기를 판단하기 위해 처리합니다. 데이터는 암호화되며, Google 안내에 따라 제3자에게 전송되지 않고 정해진 보관 기간 후 삭제됩니다. Google Play의 자체 처리에는 Google의 정책이 적용됩니다. 사용자의 항목, 날짜별 기록, 메모는 업데이트 확인에 포함하지 않습니다. 안내를 표시한 버전과 시간은 반복 안내를 줄이기 위해 기기에만 저장합니다.

3. 백업과 복원

사용자가 백업을 선택하면 기록과 설정을 담은 JSON 파일을 생성합니다. 공유할 앱이나 저장 위치는 사용자가 직접 선택하며, 선택한 서비스의 데이터 처리에는 해당 서비스의 정책이 적용됩니다. 복원할 때는 사용자가 선택한 파일만 읽습니다.

4. 선택 권한

Android 알림 권한은 사용자가 하루 기록 알림을 켤 때만 요청합니다. 알림은 기기에서 예약되며 서버에 알림 정보가 전송되지 않습니다. 알림을 거절해도 기록 기능을 사용할 수 있습니다. 연락처, 위치, 카메라, 마이크 권한은 요청하지 않습니다.

5. 보관과 삭제

기록은 사용자가 설정에서 기록 초기화를 실행하거나 앱 데이터를 삭제할 때까지 보관됩니다. 앱을 삭제하면 기기에 저장된 기록을 잃을 수 있으므로 필요한 기록은 먼저 백업해 주세요. 사용자가 외부에 저장한 백업 파일은 직접 삭제해야 합니다.
