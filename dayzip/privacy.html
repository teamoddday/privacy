DAY.zip 개인정보처리방침

시행일: 2026년 10월 6일

작성일: 2026년 10월 6일 · 적용 대상: DAY.zip Android 앱 및 웹 버전

1. 기기에 저장하는 정보

입력한 날짜, 제목, 메모, 카드 색상, 순서와 꾸미기 설정은 사용하는 기기의 앱 또는 브라우저 저장 공간에 보관합니다. 이 기록을 개발자 서버로 전송하는 기능은 없습니다. 회원가입이나 로그인을 요구하지 않습니다.

2. 안드로이드 앱의 데이터 처리

출시 준비 중인 안드로이드 앱은 화면과 기능을 앱 안에 포함하며 인터넷 연결 권한, 광고 SDK, 이용 분석 SDK를 사용하지 않습니다. 카메라, 위치, 연락처, 사진 또는 전체 파일 접근 권한을 요구하지 않습니다. 백업을 저장하거나 불러올 때는 사용자가 직접 선택한 파일에만 시스템 파일 선택기를 통해 접근합니다. 시스템 자동 앱 데이터 백업은 비활성화합니다. 위젯 표시를 위해 날짜 기록의 사본과 사용자가 선택한 표시 설정을 기기에 저장합니다. 홈 화면 위젯에는 선택한 제목과 일수가 표시됩니다. 알림창 표시 기능은 현재 제공하지 않으며 알림 권한을 요청하지 않습니다. 기기를 재시작하거나 날짜·시간대가 바뀌면 표시를 갱신합니다.

3. 웹 버전 접속

웹 버전은 화면과 설치에 필요한 파일을 호스팅 서비스에서 받아 실행합니다. 이 과정에서 호스팅 제공자의 접속 처리 및 보안 운영 정책이 적용될 수 있습니다. 웹 버전에도 날짜 기록을 서버에 동기화하는 기능이나 광고·분석 도구는 넣지 않았습니다. 웹과 안드로이드 앱의 저장 공간은 서로 다르며 자동으로 연동되지 않습니다.

4. 백업 파일과 삭제

백업 파일에는 입력한 날짜와 메모 등 기록이 포함됩니다. 파일은 사용자가 선택한 위치에 저장하며 암호화하지 않습니다. 클라우드 드라이브를 저장 위치로 선택하면 해당 서비스의 정책이 적용됩니다. 내보낸 파일의 보관과 삭제는 사용자가 관리합니다. 앱 안에서 날짜를 삭제하거나 Android 설정에서 앱 데이터를 삭제하면 앱의 기록을 제거할 수 있습니다. 웹 기록은 해당 브라우저의 사이트 데이터 삭제로 제거할 수 있습니다. 내보낸 백업 파일은 별도로 삭제해야 합니다.
