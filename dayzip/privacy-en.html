DAY.zip Privacy Policy

Last updated: October 6, 2026. Applies to the DAY.zip Android app and web version.

1. Records stored on your device

Your dates, titles, notes, card colors, order, language and appearance settings are stored in the app or browser on your device. The app has no feature that sends these records to the developer’s server. No account or login is required.

2. Android app

The Android app includes its screens and features locally. It does not request internet access and has no advertising or analytics SDKs. It does not request camera, location, contacts, photos or broad file access. For backup import and export, it accesses only the file you select through the system file picker. Automatic system app-data backup is disabled. A local copy of date records and display settings is used for home screen widgets, which show selected titles and day counts. Notification display is not currently available, and notification permission is not requested. Widget updates are requested after reboot and changes to the date, time zone or device language.

3. Web version

The web version loads app and installation files from its hosting provider. The provider’s connection processing and security policies may apply. The web version has no date-record synchronization, advertising or analytics tools. Web and Android storage are separate and do not sync automatically.

4. Backup files and deletion

Backup files include your dates, notes and settings. Files are saved to the location you select and are not encrypted. If you select cloud storage, that service’s policies apply. You manage exported files and their deletion. Delete individual dates in the app or clear the app’s data in Android settings to remove local records. For the web version, clear the browser’s site data. Exported backup files must be deleted separately.
