Rough-log 데이터 삭제 요청

Rough-log 계정을 유지하면서 일부 또는 전체 기록의 삭제를 요청할 수 있습니다. Google 계정 자체는 삭제되지 않으며, 앱을 제거했거나 로그인할 수 없어도 이메일로 요청할 수 있습니다.

앱에서 데이터 삭제

설정 → 데이터 관리 → 데이터 삭제에서 날짜별 일기와 기록 또는 모든 기록을 선택하고, 삭제 범위를 확인한 뒤 ‘삭제’를 입력해 최종 확인합니다.

웹과 앱에서 같은 계정을 사용하면 데이터 삭제가 함께 적용됩니다. 사진 한 장만 삭제하려면 오늘 또는 달력에서 해당 사진의 삭제 버튼을 이용해 주세요. 로그인할 수 없으면 아래 이메일로 요청해 주세요.

이메일로 삭제 요청

  1. Rough-log에 등록한 이메일 주소로 문의 메일을 보내 주세요.
  2. 제목: Rough-log Data Deletion Request
  3. 본문에 ‘계정 유지’를 명시하고, 삭제를 원하는 날짜 또는 ‘모든 기록’ 등 범위를 적어 주세요.
  4. 운영자가 계정 소유 여부와 관련 기록의 삭제 범위를 확인합니다.
  5. 확인된 범위를 삭제 처리하고 결과를 회신합니다.

데이터 삭제 요청 메일 작성

버튼을 누르는 것만으로 요청이 접수되지 않으며, 작성한 메일을 보내야 합니다.

메일 주소나 계정 코드만으로 소유 여부를 확정하지 않습니다. 운영자가 계정에 이미 등록·검증된 이메일로 별도의 일회용 삭제 확인값을 보내고, 소유자가 해당 값을 회신한 뒤 확인된 범위만 처리합니다. 이 값은 Google 로그인 코드가 아닙니다. 비밀번호, Google 인증 코드, 신분증 또는 일기 전문을 보내지 마세요.

등록 이메일에 접근할 수 없거나 익명 계정이라면 먼저 문의해 주세요. 안전하게 본인 확인이 되기 전에는 삭제를 실행하지 않습니다.

삭제 가능한 데이터

  • 일기 원문과 수정 이력, AI 분석 및 요약 결과
  • 연결된 사건·소비·거래 기록과 결제·환불 관계
  • 오늘의 한 페이지, 수정한 일기와 Best, 연결된 회고
  • 하루 대표 사진 파일과 연결 정보, 서비스가 보관하는 사용자 소유 첨부파일

날짜별 삭제에서는 하나의 원문에 여러 날짜가 섞여 있거나 결제·환불이 연결되어 있으면 다른 날짜의 관련 기록과 해당 월의 회고까지 삭제 범위에 포함될 수 있습니다. 확인 화면 또는 운영자의 안내에서 범위를 확인해 주세요. 파일 연결을 확인할 수 없으면 임의로 삭제하지 않고 추가 확인합니다.

현재 별도로 구현된 연간 회고는 없으며, 전체 삭제는 실제 서비스에 저장된 데이터를 대상으로 합니다.

데이터 삭제 후 유지되는 정보

Rough-log 계정, Google 로그인 연결 및 세션, 프로필과 앱 설정은 계정을 유지하는 동안 남습니다. 전체 기록을 삭제한 뒤에도 같은 계정으로 새 일기를 작성할 수 있습니다. 계정 정보까지 삭제하려면 계정 삭제를 요청해 주세요.

보관되는 정보와 기간

완료된 서버 삭제 작업에서는 계정 식별자와 처리 대상 목록을 제거합니다. 재시도 확인용 요청 번호·상태·시각·확인용 해시는 완료 7일 후 일일 정리 작업으로 제거하며, 정상 운영 시 다음 정리 시점까지 최대 약 하루가 추가될 수 있습니다. 실패한 작업은 재처리를 위해 최소 식별 정보와 상태를 완료 시까지 유지합니다.

직접 내보낸 JSON·CSV 등 파일은 사용자가 별도로 삭제해야 합니다. 문의 이메일과 Supabase·Vercel·AI 제공자의 백업·기술 로그는 별도 관리 대상입니다. 해당 서비스의 실제 보관·만료 기간 및 법적 보관 의무는 확인 중이며, 확인되지 않은 기간이나 즉시 완전 소거를 약속하지 않습니다. 보관이 필요한 항목은 확인된 근거·대상·기간을 요청 처리 시 안내합니다.

이메일 요청은 접수 후 소유 확인과 범위 확인을 거쳐 처리 일정을 안내하고 완료 결과를 회신합니다. 일률적인 처리 기한은 아직 확정되지 않았습니다.
